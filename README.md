# 住进理想 · v5 终版

## 开始玩

用新版 Edge 或 Chrome 打开项目根目录中的 **little-room.html**。引擎、模型与界面都已内嵌，无需联网、安装依赖或启动服务。继续使用同一路径的文件和同一浏览器，方便读取原存档。源码中的 dist/index.html 不是双击入口。

本版保留你在 v4 中加入的 35 件家具、6 张户型、6 份委托、空间评分、星级、二周目与作品集备份；没有重新加入宠物内容。仓库仅包含最新版，保留旧版本存档兼容逻辑。

## 本轮完善

- 空间评分识别隔墙、家具遮挡和座椅拉出空间；一把椅子只能服务一个桌面位置。距离和角度使用细化评分，低矮茶几不会阻断电视视线。缺少可用座位等关键问题会阻止委托完成。
- 结果页的空间建议附带「定位家具」，点击后退出结果页、调整视角并框选相关家具。结果同时显示本次星级与历史最佳。
- 引导会随当前作品保存，刷新、撤销、重做后自动续接；切到其他作品时暂停，返回时继续。点击顶部「?」中的「继续 / 重新学习引导」可再次学习。目标家具会自动滚动到可见位置，手机引导不再遮挡底部撤销栏。
- 整个作品集支持合并和替换，操作前展示作品数量。合并为导入作品重新分配编号，保留双方徽章、取最高星级；超过 12 件时禁止合并。两种导入都会留下本机恢复副本。
- 在作品集点击「恢复上一次作品集」可撤回上次合并或替换；恢复时也会保存当前作品集作为新的副本。本机副本不是云备份，仍建议下载 JSON。
- 编辑时复用未变化的家具模型，移动不重建模型，改色只重建对应家具；自动保存合并短时间的连续操作，缩略图延后生成。画面静止时停止连续重绘。

## 六份不同的新版二周目

首次完成对应委托后可接取。新版不统一限制三种主色，各委托增加不同的生活需求，并要求空间关系至少 85 分。

| 委托 | 进阶预算 | 新增生活需求 |
| --- | --- | --- |
| 日光里的工作室 | ¥12,750 | 床边柜上的台灯，以及一把休闲椅 |
| 两个人的日常 | ¥18,700 | 床的两侧各安排一个床边柜 |
| 阳台上的周末 | ¥15,300 | 阳台两处阅读座位，阳台边几上有书 |
| 各自专注，一起生活 | ¥20,400 | 两张书桌相距至少 2.2 米，每张桌上都有书 |
| 转角有烟火 | ¥17,000 | 同一餐桌周围摆四把朝向餐桌的独立餐椅 |

已保存的 v4 二周目保留原有预算与三色目标，新建二周目使用上表规则。新版修正后的空间评分也适用于旧作品，因此原有布置可能收到新的调整建议，历史徽章与星级会保留。

## 操作

点击家具卡，再点击房间放置；绿色可放，红色会说明原因。拖动已有家具移动，拖动空白转动视角，滚轮缩放。底栏选择每次旋转 15°、45° 或 90°，按 R 或点击旋转；方向键微调。墙饰上下键调高度。

家具可换色、复制；勾选「连续放置」可连续复制。餐桌附近约两米内的书椅或长凳可以组合，移动、旋转和删除作用于整组及桌面摆件。桌面台灯、花瓶和书本会跟随承托物。地毯可铺在家具下方。

Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做；Delete 删除，Esc 取消。编辑历史仅保留当前会话，引导进度和作品会保存。灯具与电视支持单独开关，窗帘与日夜切换位于场景右上角。

## 成长与存档

每份不同委托首次完成获得 100 经验。Lv.2 / Lv.3 / Lv.4 分别需要 100 / 300 / 500 经验，解锁家具系列、配色与进阶委托。自由模式开放全部家具、配色和户型。

作品集最多 12 件作品。单作品导出包含当前作品、成长与星级；整个作品集备份包含全部作品及引导进度。v5 支持导入 v2–v5 单作品，以及原有格式的作品集；v1 浏览器旧数据仍可迁移。移动 HTML、换浏览器或清理浏览器数据前，请先备份整个作品集。

恢复副本只保留上一份。替换失败时会提示，存储空间不足不会直接改掉内存里的当前作品集。合并不去重相同设计，而是作为新作品保留。

## 开发与验证

- src/scene.js：模型、户型、场景及按需渲染。
- src/game.js：编辑、评分界面、保存、作品集合并与回退。
- src/living.js：成长、引导、辅助线、房间互动。
- src/ui.js / src/main.js：家具库、界面和输入启动逻辑。
- dist/rules.js：碰撞、空间配对、通行、二周目目标与存档校验。
- dist/index.html / style.css：界面和响应式布局。

`node build.cjs` 重新生成 dist/app.js 和项目根目录的 little-room.html。

`node test-all.cjs` 执行 68 项基础、67 项进阶、52 项 v5 回归，共 187 项检查，以及独立文件完整性检查。tests/v5-*.json 提供六份可导入的进阶示范；v5-portfolio.json 是作品集导入示范。示范验证可行性，不会自动添加到玩家的新游戏。

详细验证范围见 VALIDATION.md。性能验证覆盖模型复用与按需调度，不代表所有手机上的帧率测试。游戏仍为离线单机，无云存档或联机。Three.js 0.170.0 使用 MIT 许可，版权声明保留在内嵌源码中。

## 维护流程

安装 Node.js 18 或更高版本，在项目根目录执行：

```sh
npm run build
npm test
```

项目不需要安装第三方 npm 依赖；Three.js 已随项目保存。构建后双击根目录的 little-room.html 即可游玩。

修改 src/ 中的逻辑、dist/rules.js 或 dist/index.html、dist/style.css 后重新构建，并将源码与生成的 dist/app.js、little-room.html 一起提交。不要直接编辑生成文件。tests/ 中的 JSON 是可导入示范，不是个人存档；test-v2.cjs、test-v3.cjs 是当前版本的兼容性回归测试，不是历史游戏版本。

仓库不包含历史备份、预览截图、压缩交付包或本机托管配置。VALIDATION.md 记录历史实测范围，新增改动请更新验证记录。
