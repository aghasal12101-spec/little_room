v6 把六张户型换成参照纽约真实公寓的格局，重做了画面质感和镜头交互。35 件家具、6 份委托、空间评分、星级、二周目与作品集备份全部保留，旧存档可以直接读取。

## 画面与镜头

- 透视镜头取代原来的正交小模型视角；人字拼与长条木地板、黑白格厨房地砖、六角马赛克卫浴地砖、地铁砖墙裙、红砖墙均为程序生成的真实比例贴图。
- 阳光从临街窗户照进来，在地板上留下窗格光斑；环境光反射、接触阴影和墙角暗部让家具落地。夜间每个房间亮起吸顶灯，落地灯和台灯各自打光。
- 双悬窗、窗帘、铸铁暖气片、白色线脚与踢脚线、五格门板、壁炉和窗外的街景都按纽约老公寓的样子建模。
- 挡住视线的墙不再整面消失，而是平滑降到半人高并露出墙体截面，家具与墙不会穿插；俯视时自动变成平面图。

## 操作

- 左键拖动空白处旋转，右键或 Shift 拖动平移，滚轮朝鼠标位置缩放，可以一直拉近到家具跟前。手机：单指拖动，双指缩放与平移。
- 点 👁 或按 V「走进房间」：以 1.55 米的视线高度站在屋里，拖动环顾四周，W / S 或滚轮前后走动，A / D 横移，再按一次回到全景。
- 没有选中家具时，WASD / 方向键移动视角，Q / E 转动，+ / − 缩放；选中家具时方向键按屏幕方向微调位置。
- 点击家具卡，再点击房间放置；绿色可放，红色会说明原因。拖动已有家具移动。底栏选择每次旋转 15°、45° 或 90°，按 R 或点击旋转。挂画和钟挂在任意一面立着的室内墙上，避开窗户、橱柜和壁炉；上下键调高度。
- 家具可换色、复制；勾选「连续放置」可连续复制。餐桌附近约两米内的书椅或长凳可以组合。桌面台灯、花瓶和书本会跟随承托物。地毯可铺在家具下方。
- Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做；Delete 删除，Esc 取消。灯具与电视支持单独开关，窗帘与日夜切换位于场景右上角。

## 成长与存档

旧版（v1–v5）存档会自动迁移到新户型：仍然放得下的家具原样保留，和墙体、橱柜、卫生间等冲突的家具会被收起，并提示数量；读取前的原始数据保存为本机恢复备份。

每份不同委托首次完成获得 100 经验。Lv.2 / Lv.3 / Lv.4 分别需要 100 / 300 / 500 经验，解锁家具系列、配色与进阶委托。自由模式开放全部家具、配色和户型。

作品集最多 12 件作品。单作品导出包含当前作品、成长与星级；整个作品集备份包含全部作品及引导进度。v5 支持导入 v2–v5 单作品，以及原有格式的作品集；v1 浏览器旧数据仍可迁移。移动 HTML、换浏览器或清理浏览器数据前，请先备份整个作品集。

恢复副本只保留上一份。替换失败时会提示，存储空间不足不会直接改掉内存里的当前作品集。合并不去重相同设计，而是作为新作品保留。

## 开发与验证

- src/data.js：家具目录与六套纽约户型（墙体、门窗、房间、内置厨房与卫浴、暖气片、功能区）。
- src/rules.js：碰撞、墙面挂件、通行、空间配对、目标、存档校验与旧档修复（生成 dist/rules.js）。
- src/textures.js / src/models.js：程序贴图、材质库、家具与卫浴厨房模型。
- src/scene.js：渲染器、户型搭建、灯光、透视镜头、墙体降低与按需渲染。
- src/game.js / src/living.js / src/ui.js / src/main.js：编辑、评分、作品集、引导、家具库与输入。
- dist/index.html / style.css：界面和响应式布局。

`node build.cjs` 重新生成 dist/app.js、dist/rules.js 和项目根目录的 little-room.html。

`node test-all.cjs` 执行 272 项户型 / 规则 / 示范设计 / 存档检查、20 项引导 / 作品集 / 模型复用 / 渲染调度检查，以及单文件打包检查。tests/designs.cjs 为六份委托各提供一套手工摆放的示范，并验证每份二周目都可完成；tests/v6-*.json 是可导入的示范存档，tests/legacy-v5-coder.json 用于验证旧档修复。

游戏仍为离线单机，无云存档或联机。Three.js 0.170.0 使用 MIT 许可，版权声明保留在内嵌源码中。

## 维护流程

安装 Node.js 18 或更高版本，在项目根目录执行：

```sh
npm run build
npm test
```

项目不需要安装第三方 npm 依赖；Three.js 已随项目保存。构建后双击根目录的 little-room.html 即可游玩。

修改 src/ 或 dist/index.html、dist/style.css 后重新构建，并将源码与生成的 dist/app.js、little-room.html 一起提交。不要直接编辑生成文件。tests/ 中的 JSON 是可导入示范，不是个人存档。

仓库不包含历史备份、预览截图、压缩交付包或本机托管配置。VALIDATION.md 记录历史实测范围，新增改动请更新验证记录。
